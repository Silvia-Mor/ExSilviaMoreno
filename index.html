1. Biblioteca API - Inicio

Esta aplicación permite consultar un catálogo de libros mediante una API REST.

Funcionalidades

  • Consultar todos los libros
  • Buscar un libro mediante su identificador

Tecnologías utilizadas

  • Node.js
  • Express
  • JSON

Consulta la página de instalación para poner en marcha la API.

Objetivo: reproducit la estructura de títulos, listas y enlace interno.

2. Instalación de la API

Requisitos previos

  • Node.js 18 o superior
  • npm
  • Git

Pasos de instalación

  1. Clonar el repositorio
  2. Acceder al directorio api
  3. Instalar las dependecias
  4. Iniciar el servidor

Comandos

    cd api
    npm install
    npm start

Dirección del servicio

http://localhost:3000

Importante: El servidor debe estar iniciado para realizar las pruebas.

3. Uso de la API
